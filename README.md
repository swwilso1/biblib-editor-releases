# Biblib Editor releases

Biblib Editor is a desktop app for creating and editing biblib libraries, the
content bundles used by Biblioscribe duplicators.

This repository holds the app's release builds. Download the installer for
your platform from the [latest release](https://github.com/swwilso1/biblib-editor-releases/releases/latest).

Each release also includes a `latest.json` file. Installed copies of Biblib
Editor read it to find and install updates automatically, so don't rename or
remove release files.
